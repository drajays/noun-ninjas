📖 What is a Noun?

A noun is a word used as the name of a person, place, or thing.

💡 TipEverything you can see, touch, or think about has a name — and that name is a noun!

⚤ Gender of Nouns

Living beings are either male or female. A noun can tell us the gender!

📌 4 Genders Masculine = male (boy, lion, hero)
Feminine = female (girl, lioness, heroine)
Common = either male or female (parent, child, friend)
Neuter = neither (book, pen, tree)

🔢 Number – Singular & Plural

A noun that denotes one person or thing is Singular. A noun that denotes more than one is Plural.

🌳 tree
Singular → trees (Plural)
📦 box
Singular → boxes (Plural)
🐂 ox
Singular → oxen (Plural)
👨 man
Singular → men (Plural)

📝 Rule 1: Add -s

Most nouns add -s to form the plural.

boy → boys
➕ -s
girl → girls
➕ -s
book → books
➕ -s
pen → pens
➕ -s

📝 Rule 2: Add -es (-s, -sh, -ch, -x, -o)

Nouns ending in -s, -sh, -ch (soft), -x add -es. Most nouns ending in -o also add -es.

class → classes
🔚 -s
dish → dishes
🔚 -sh
match → matches
🔚 -ch
box → boxes
🔚 -x
mango → mangoes
🔚 -o
potato → potatoes
🔚 -o
hero → heroes
🔚 -o

📝 Rule 3: Change -y to -ies

Nouns ending in -y (preceded by a consonant) change -y → -i and add -es.

baby → babies
y→i + es
lady → ladies
y→i + es
city → cities
y→i + es
army → armies
y→i + es

📝 Rule 4: Change -f/-fe to -ves

Some nouns ending in -f or -fe change to -ves.

f→ves

fe→ves

sheaf → sheaves
f→ves
